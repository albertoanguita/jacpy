# jacpy
A utility package for Python



To publish new releases, follow this guide. All the work is done in GitHub.

https://medium.com/@blackary/publishing-a-python-package-from-github-to-pypi-in-2024-a6fb8635d45d

Go to GH, click on Releases -> Draft a new release

Create new release, select branch and tag the version. Publish release


This runs a configured workflow that can be seen under "Actions". It just runs the python-publish.yaml script
